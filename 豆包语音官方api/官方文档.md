## 1. 接口说明 [#](https://www.volcengine.com/docs/6561/1257584?lang=zh#_1-%E6%8E%A5%E5%8F%A3%E8%AF%B4%E6%98%8E)

## 2. 身份认证 [#](https://www.volcengine.com/docs/6561/1257584?lang=zh#_2-%E8%BA%AB%E4%BB%BD%E8%AE%A4%E8%AF%81)

认证方式使用 Bearer Token，在请求的 header 中加上 `"Authorization": "Bearer; {token}"`，并在请求的 json 中填入对应的 appid。

注意

Bearer 和 token 使用分号 ; 分隔，替换时请勿保留{}
